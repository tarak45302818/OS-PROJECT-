# OS-PROJECT-
CPU schedular simulator
his repository showcases a hands-on project exploring fundamental concepts in Operating Systems, specifically focusing on CPU process scheduling.

The core of the project is a simulation designed to model how a CPU manages multiple competing processes. We implemented and analyzed several key algorithms, including First-Come, First-Served (FCFS), Shortest Job First (SJF), and Round Robin (RR).

The simulation reads process details (like arrival time and burst time) and calculates essential performance metrics such as Average Waiting Time, Average Turnaround Time, and CPU Utilization. The results are outputted to demonstrate the trade-offs and efficiencies of each scheduling approach. This project provides a practical understanding of how different policies impact system performance and resource management.
